## Premium、Standard、Global 三条线路差在哪

这三个词不是营销包装，是三种不同的网络定位，选错了比买贵了更麻烦。

**Premium** 是面向中国大陆的优化线路，洛杉矶节点明确标注走 CN2/CMIN2。三档里最贵，年付比 Global 贵 $20。需要国内访问稳定、晚高峰不掉速，这 $20 是整套方案里唯一不能省的部分。

**Standard** 是常规国际线路，价格居中，没有针对特定地区做优化。适合访客分散在多个地区、不特别依赖中国大陆访问速度的业务。

**Global** 走 PCCW、COGENT 这类国际带宽，延迟大致在 120ms 到 200ms 之间，用来做跨国数据传输、访问国际站点成本最低。它明确不是中国大陆直连优化产品，拿它当 CN2 用会失望。

机房怎么选，看你的用户在哪儿。台湾、马尼拉、新加坡辐射东南亚和亚太本地访问；洛杉矶覆盖美西，同时承担回国线路的入口；香港、日本、英国、德国对应各自区域。香港机房的带宽成本普遍高于美国，同配置卖得贵是行业现实，不是某一家的问题。

## 常见问题

**年付还是月付？**

新品牌、无无理由退款，这两条加在一起，答案是先月付。$4 的 Startup 跑满一个月，确认延迟和稳定性符合预期，再转年付。已经在同一家稳定用了几年的商家另说。

**台湾和洛杉矶怎么选？**

访客主要在中国大陆，选洛杉矶 Premium，CN2/CMIN2 是它家唯一针对回国优化的线。访客在台湾本地或东南亚，台湾节点 $24.99/年就够，没必要为用不上的回国线路多付 $25。

**一定要 CN2 GIA 吗？**

不一定。LightLayer 的 Premium 标的是 CN2/CMIN2，和全程三网回程 GIA 不是一回事。如果你的用途是建站给国内用户访问，Premium 档够用；如果对晚高峰稳定性有硬要求，AkkoCloud 那种明确写三网回程 GIA 的产品更对口。

**退款怎么算？**

只有供应商责任导致的问题才受理，正价和促销产品都不支持无理由退款。下单前把机房、线路、配置确认清楚，比事后申请退款有效。
